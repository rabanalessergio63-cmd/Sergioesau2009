# 🚀 Portafolio Web Personal | Sergio Rabanales

¡Bienvenido a mi repositorio principal! Este proyecto es mi sitio web de portafolio personal interactivo, desarrollado desde cero con un diseño moderno, transiciones fluidas y soporte dinámico para múltiples temas visuales e idiomas.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio web.
* **CSS3 Avanzado:** Estilos personalizados, diseño responsivo (*Flexbox* y *CSS Grid*), efectos de enfoque interactivo (*Focus/Hover* con `:has()`), animación de tarjetas y variables CSS (`:root`).
* **JavaScript (ES6):** Lógica interactiva para la conmutación de temas visuales y soporte de idiomas.
* **FontAwesome / Google Fonts:** Tipografías modernas (*Outfit*, *Plus Jakarta Sans*) e iconografía vectorial.

---

## ✨ Características Principales

* **🎨 Selector de Temas Dinámico:** Permite cambiar en tiempo real entre 3 estilos visuales (Oscuro Morado, Claro y Azul Pro).
* **🌐 Multilingüe:** Preparado para conmutación de idioma mediante selector interactivo.
* **🎯 Efecto Foco Interactiva (Hover Focus):** Al pasar el cursor sobre cualquier elemento o sección, el resto del sitio web aplica un leve desenfoque (*blur*) y escala la tarjeta activa para resaltar el contenido principal.
* **📱 Diseño 100% Responsivo:** Adaptación completa a dispositivos móviles, tabletas y pantallas de escritorio.
* **📄 Sección de Curriculum Vitae:** Enlace directo para visualización y descarga del CV en formato PDF.
